# Railway Track Detection Using ResNet

## Project Overview
This project focuses on railway track detection using deep learning techniques. The system was initially developed using SegNet and later enhanced using ResNet architecture to improve classification accuracy and robustness.

## Technologies Used
- Python
- Deep Learning
- ResNet
- Computer Vision

## Features
- Railway track identification from images
- Improved feature extraction using ResNet
- Better accuracy compared to SegNet
- Infrastructure monitoring and safety applications
